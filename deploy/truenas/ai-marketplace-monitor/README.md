# AI Marketplace Monitor

[AI Marketplace Monitor](https://github.com/BoPeng/ai-marketplace-monitor) watches Facebook Marketplace for the items you want, rates each new listing with AI, and notifies you of good deals by email, phone, Discord, Slack, Telegram and more.

Open the web UI and sign in with the Facebook username and password set in the app's configuration. aimm logs in to Facebook in its own browser; if Facebook asks for a CAPTCHA or a security code, click **Open browser** in the web UI and complete it there. The default configuration uses one [UnitySVC](https://unitysvc.com) API key for the AI that rates listings and for email and phone notifications.
